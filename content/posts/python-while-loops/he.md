[הפוסט על לולאות](he/posts/python-loops/) הציג את `while` הבסיסי, ‏`break`, ‏`continue` ו-`else`. הפוסט הזה עוסק בכתיבת לולאות `while` שעוצרות כשהן צריכות.

כל הדוגמאות הורצו עם Python 3.13 ונבדקו מול [התיעוד של פקודת `while`](https://docs.python.org/3/reference/compound_stmts.html#the-while-statement) ו-[PEP 572](https://peps.python.org/pep-0572/) על `:=`.

## מתי while עדיף על for

‏`for` מתאים כשיש משהו לעבור עליו: רשימה, מחרוזת, `range`. ‏`while` מתאים כשמספר הסיבובים תלוי במה שקורה בתוך הלולאה. ספירת הספרות של מספר היא דוגמה:

```python
n = 90210
digits = 0
while n > 0:
    n //= 10
    digits += 1
print(digits)
```

```text
5
```

אף אחד לא יודע מראש כמה פעמים `n //= 10` ירוץ. הלולאה מגלה את זה.

## שלושה חלקים: התחלה, תנאי, עדכון

לכל לולאת `while` יש ערך התחלתי, תנאי שנבדק לפני כל סיבוב, ועדכון שמקרב את הערך למצב שבו התנאי שקרי. בלי העדכון, הלולאה לא נגמרת. הגרסה השקטה של הבאג הזה היא `continue` שמדלג על העדכון:

```python
i = 0
evens = []
while i < 10:
    i += 1
    if i % 2:
        continue
    evens.append(i)
print(evens)
```

```text
[2, 4, 6, 8, 10]
```

‏`i += 1` היא השורה הראשונה בגוף הלולאה, אז כל מסלול דרך הלולאה מריץ אותה. אם `i += 1` היה בסוף, המספר האי-זוגי הראשון היה מדלג עליו עם `continue`, ו-`i` היה נשאר 1 לנצח.

## לולאות עם ערך עצירה ו-:=

ערך עצירה (sentinel) הוא ערך שמשמעותו "עצור", כמו `quit` שהמשתמש מקליד. הצורה הקלאסית קוראת פעם אחת לפני הלולאה ופעם נוספת בסוף הגוף. אופרטור הוולרוס `:=` ‏(Python 3.8) מבצע השמה בתוך התנאי, כך שהקריאה מופיעה פעם אחת:

```python
lines = iter(["add milk", "add bread", "quit", "add eggs"])

while (line := next(lines)) != "quit":
    print("got:", line)
print("last read:", line)
```

```text
got: add milk
got: add bread
last read: quit
```

‏`line := next(lines)` שומר את הערך ב-`line` וגם מחזיר אותו, כך שההשוואה משתמשת בו. הסוגריים הכרחיים: בלעדיהם, `line` היה מקבל את התוצאה של `!=`, כלומר `True` או `False`. בתוכנית אמיתית, `input("> ")` בא במקום `next(lines)`.

## ריקון רשימה

רשימה ריקה היא שקרית, אז `while items:` רץ עד שהרשימה מתרוקנת. יחד עם `pop()` זה מתאים לעבודה שמייצרת עוד עבודה, כמו מעבר על עץ תיקיות או על רשימות מקוננות:

```python
todo = [1, [2, [3, 4]], 5]
flat = []
while todo:
    item = todo.pop()
    if isinstance(item, list):
        todo.extend(item)
    else:
        flat.append(item)
print(sorted(flat))
```

```text
[1, 2, 3, 4, 5]
```

לולאת `for` על `todo` לא הייתה יכולה לעשות את זה: הרשימה משתנה בזמן שקוראים אותה. כאן התנאי נבדק מחדש בכל סיבוב, אז פריטים ש-`extend` הוסיף נאספים.

## הגבלת מספר הסיבובים

לולאה שמחכה למשהו מחוץ לקוד שלכם (קריאת רשת, קובץ, משתמש) צריכה גבול עליון. ה-`else` מהפוסט על לולאות מתאים כאן: הוא רץ רק כשהלולאה נגמרה בלי `break`.

```python
replies = iter([503, 503, 200])
attempt = 0
while attempt < 5:
    attempt += 1
    status = next(replies)
    print("attempt", attempt, "->", status)
    if status == 200:
        break
else:
    print("gave up")
```

```text
attempt 1 -> 503
attempt 2 -> 503
attempt 3 -> 200
```

אם כל חמש התשובות היו 503, הלולאה הייתה נגמרת בגלל התנאי ומדפיסה `gave up`. לולאת ניסיונות אמיתית גם ממתינה בין ניסיון לניסיון (`time.sleep`).

## טעויות נפוצות

- **‏`=` בתנאי.** ‏`while x = 5:` הוא `SyntaxError`. משווים עם `==`, או משתמשים ב-`:=` כשבאמת רוצים השמה.
- **השוואת שברים עם `!=`.** ‏`x = 0` ועוד `0.1` עשר פעמים נותן `0.9999999999999999`, אז `while x != 1:` לא עוצר אף פעם. השתמשו ב-`<` או ב-`<=`.
- **עדכון רק בענף אחד.** אם ענף `if` אחד משנה את הערך והשני לא, הלולאה יכולה להיתקע בענף השני. שימו את העדכון במקום שכל מסלול עובר בו.
