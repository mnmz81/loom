Python מחשב בדיוק כמו שמצפים, עם כמה פרטים שחשובים: `/` ו-`//` הן פעולות שונות, `%` עובד עם מספרים שליליים בצורה מסוימת, ו-`round()` לא תמיד מעגל חצאים כלפי מעלה. הפוסט הזה מכסה את האופרטורים, הפונקציות הנפוצות וההפתעות.

כל דוגמה כאן הורצה עם Python 3.13. הכללים נבדקו מול [התיעוד הרשמי של טיפוסי המספרים](https://docs.python.org/3/library/stdtypes.html#numeric-types-int-float).

## האופרטורים הבסיסיים

```python
print(7 + 2, 7 - 2, 7 * 2)
print(2 ** 10)
```

```text
9 5 14
1024
```

`**` הוא אופרטור החזקה. `2 ** 10` הוא 2 בחזקת 10.

האופרטורים פועלים לפי סדר הקדימויות הרגיל: קודם `**`, אחר כך `*`, `/`, `//` ו-`%`, ואז `+` ו-`-`. כשלא בטוחים, משתמשים בסוגריים:

```python
print(2 + 3 * 4 ** 2)
```

```text
50
```

`4 ** 2` הוא 16, `3 * 16` הוא 48, ו-`2 + 48` הוא 50.

## חילוק אמיתי וחילוק עם עיגול למטה

`/` תמיד נותן float, ו-`//` מעגל למטה למספר שלם:

```python
print(7 / 2)
print(7 // 2)
print(10 / 4 * 2)
```

```text
3.5
3
5.0
```

`//` מעגל לכיוון מינוס אינסוף, ולא לכיוון האפס. התיעוד נותן את הדוגמאות `1//2` הוא `0`, `(-1)//2` הוא `-1`, ו-`1//(-2)` הוא `-1`. אותו כלל חל על floats:

```python
print(1 // 0.5, 7.5 % 2)
```

```text
2.0 1.5
```

## השארית: %

`%` נותן את השארית אחרי החילוק:

```python
print(7 % 2)
print(10 % 3 == 1)
```

```text
1
True
```

במספרים שליליים, התוצאה לוקחת את הסימן של המחלק:

```python
print(-7 // 2, -7 % 2)
```

```text
-4 1
```

`-7 // 2` הוא -4, כי הוא מעגל למטה. `-7 % 2` הוא 1, כי `(-4) * 2 + 1` שווה ל-`-7`. זה חשוב כשמשתמשים ב-`%` כדי לחזור להתחלה ברשימה.

`divmod` מחזירה את שתי התוצאות יחד, כזוג `(x // y, x % y)`:

```python
print(divmod(17, 5))
```

```text
(3, 2)
```

## אופרטורי השמה

`+=`, `*=` ואחרים מעדכנים משתנה במקום:

```python
x = 5
x += 2
x *= 3
print(x)
```

```text
21
```

## פונקציות מובנות

`abs` מחזירה ערך מוחלט. `round` מעגלת למספר הקרוב:

```python
print(abs(-3.5))
print(round(2.5), round(3.5))
print(round(2.675, 2))
```

```text
3.5
2 4
2.67
```

`round(2.5)` הוא 2, ו-`round(3.5)` הוא 4. Python מעגל חצאים למספר הזוגי הקרוב. `round(2.675, 2)` נותן 2.67, כי 2.675 נשמר כ-float קצת קטן מ-2.675.

## המודול math

לשורש ריבועי, עיגול למעלה או למטה ופונקציות נוספות מייבאים את `math`:

```python
import math

print(math.sqrt(16), math.floor(3.7), math.ceil(3.2))
```

```text
4.0 3 4
```

`math.floor` מעגל למטה, ו-`math.ceil` מעגל למעלה. שתיהן מחזירות int.

## floats אינם מדויקים

מחשבים שומרים רוב השברים העשרוניים כקירוב:

```python
print(0.1 + 0.2)
```

```text
0.30000000000000004
```

זו לא באג של Python. ככה פועלים floats בבסיס בינארי. לכסף או להשוואות מדויקות כדאי להשתמש במודול `decimal`, או להשוות עם סטייה מותרת במקום `==`.

## טעויות נפוצות

- **ציפייה ש-`//` יעגל לכיוון האפס.** `-7 // 2` הוא -4, לא -3.
- **השוואה של floats עם `==`.** `0.1 + 0.2 == 0.3` הוא `False`.
- **הסתמכות על `round` לעיגול "רגיל".** חצאים הולכים למספר הזוגי, ולכן `round(2.5)` הוא 2.
- **בלבול בין `/` ו-`//`.** `/` נותן float גם לתוצאה שלמה, כמו `10 / 2` שנותן `5.0`.
