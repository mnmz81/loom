Python מחשבת כמו שמצפים, עם כמה פרטים שחשובים: `/` ו-`//` הן פעולות שונות, `%` מתנהג במיוחד עם מספרים שליליים, ו-`round()` לא תמיד מעגל חצאים כלפי מעלה.

כל דוגמה הורצה עם Python 3.13 ונבדקה מול [התיעוד של טיפוסי המספרים](https://docs.python.org/3/library/stdtypes.html#numeric-types-int-float).

## האופרטורים הבסיסיים

```python
print(7 + 2, 7 - 2, 7 * 2)
print(2 ** 10)
```

```text
9 5 14
1024
```

`**` הוא אופרטור החזקה: `2 ** 10` הוא 2 בחזקת 10.

סדר הקדימויות הרגיל: קודם `**`, אחר כך `*`, `/`, `//` ו-`%`, ואז `+` ו-`-`. כשלא בטוחים, סוגריים:

```python
print(2 + 3 * 4 ** 2)
```

```text
50
```

`4 ** 2` הוא 16, `3 * 16` הוא 48, ו-`2 + 48` הוא 50.

## חילוק אמיתי וחילוק עם עיגול למטה

`/` תמיד נותן float, ו-`//` מעגל למטה למספר שלם:

```python
print(7 / 2)
print(7 // 2)
print(10 / 4 * 2)
```

```text
3.5
3
5.0
```

`//` מעגל לכיוון מינוס אינסוף, לא לכיוון האפס: `1//2` הוא `0`, ‏`(-1)//2` הוא `-1`, ו-`1//(-2)` הוא `-1`. אותו כלל חל על floats:

```python
print(1 // 0.5, 7.5 % 2)
```

```text
2.0 1.5
```

## השארית: %

`%` נותן את השארית אחרי החילוק:

```python
print(7 % 2)
print(10 % 3 == 1)
```

```text
1
True
```

במספרים שליליים, התוצאה לוקחת את הסימן של המחלק:

```python
print(-7 // 2, -7 % 2)
```

```text
-4 1
```

`-7 // 2` הוא -4, כי מעגלים למטה, ו-`-7 % 2` הוא 1, כי `(-4) * 2 + 1` שווה ל-`-7`. זה חשוב כש-`%` משמש לחזרה להתחלה ברשימה.

`divmod` מחזירה את שתי התוצאות יחד, כזוג `(x // y, x % y)`:

```python
print(divmod(17, 5))
```

```text
(3, 2)
```

## אופרטורי השמה

`+=`, `*=` ואחרים מעדכנים משתנה במקום:

```python
x = 5
x += 2
x *= 3
print(x)
```

```text
21
```

## פונקציות מובנות

`abs` מחזירה ערך מוחלט. `round` מעגלת למספר הקרוב:

```python
print(abs(-3.5))
print(round(2.5), round(3.5))
print(round(2.675, 2))
```

```text
3.5
2 4
2.67
```

Python מעגלת חצאים למספר הזוגי הקרוב. `round(2.675, 2)` נותן 2.67, כי 2.675 נשמר כ-float קצת קטן ממנו.

## המודול math

לשורש ריבועי, עיגול למעלה או למטה ופונקציות נוספות מייבאים את `math`:

```python
import math

print(math.sqrt(16), math.floor(3.7), math.ceil(3.2))
```

```text
4.0 3 4
```

`math.floor` מעגל למטה ו-`math.ceil` למעלה, ושתיהן מחזירות int.

## floats אינם מדויקים

מחשבים שומרים את רוב השברים העשרוניים כקירוב:

```python
print(0.1 + 0.2)
```

```text
0.30000000000000004
```

זה לא באג של Python: ככה פועלים floats בבסיס בינארי. לכסף או להשוואות מדויקות משתמשים במודול `decimal`, או משווים עם סטייה מותרת במקום `==`.
