דף עזר לפקודות ה-slash של Claude Code, מקובץ לפי מה שעושים באמצע עבודה. הרשימה נבדקה מול התיעוד הרשמי נכון ל-2026-10-08 (גרסה 2.1.294). פקודה שנוספה או השתנתה לאחרונה מסומנת בכוכבית (*).

## מה השתנה מאז הרשימה הקודמת

- `/ultraplan` **הוסרה**. במקומה משתמשים ב-`/plan`.
- `/vim` **הוסרה** (2.1.92). מעבר בין מצב Vim לרגיל נעשה ב-`/config` ← Editor mode.
- `/pr-comments` **הוסרה** (2.1.91). מבקשים מ-Claude ישירות לקרוא את תגובות ה-PR.
- `/fork` ו-`/subtask` חילקו ביניהן את התפקיד. `/fork` מעתיקה את השיחה לסשן רקע נפרד, ו-`/subtask` שולחת תת-סוכן שמחזיר את התוצאה לשיחה הנוכחית.
- `/checkup` לא מופיעה בתיעוד הרשמי. בדיקת ההגדרות נעשית היום ב-`/doctor`.
- `/effort` קיבלה `status` ו-`ultracode on|off`. `ultracode` כבר לא רמה אלא מתג נפרד.
- נוספו: `/subtask`, `/autocompact`, `/focus`, `/import`, `/output-style`, `/skill-doctor`, `/workflows`, `/list-agents`, `/artifacts` ועוד. הפירוט בהמשך.
- ב-`/code-review` נוסף `--max-findings`, וב-`/claude-api` נוספה האפשרות `managed-agents-onboard`.

## הפקודות היומיומיות

- `/init` — סורקת את הפרויקט ויוצרת קובץ `CLAUDE.md` התחלתי. מריצים פעם אחת לכל פרויקט.
- `/help` — רשימת כל הפקודות, כולל פקודות מותאמות, תוספים ו-MCP.
- `/compact [הוראות]` — מסכמת את השיחה כדי לפנות מקום בחלון ההקשר. היא עצמה צורכת טוקנים, ואפשר להוסיף הוראות על מה לשמר.
- `/clear [שם]` — שיחה חדשה בהקשר ריק. השיחה הקודמת נשארת על הדיסק וחוזרים אליה עם `/resume`. אפשר לתת לה שם. כינויים: `/reset`, `/new`.
- `/usage` — עלות הסשן, מגבלות התוכנית וסטטיסטיקות. כינויים: `/cost`, `/stats`.
- `/plan [תיאור]` — מצב תכנון: רואים אילו קבצים Claude ישנה, למה ובאיזה סדר, לפני שמשהו משתנה. עם תיאור הוא מתחיל לתכנן מיד.

## ניהול הקשר ושיחה

- `/context [all]` — הקשר בתצוגת רשת צבעונית, עם המלצות. `all` מראה פירוט לכל פריט.
- `/btw [שאלה]` — שאלת צד בלי לנפח את השיחה. בלי שאלה מוצגות שאלות הצד הקודמות.
- `/recap` — סיכום בשורה אחת של הסשן.
- `/export [קובץ]` — ייצוא השיחה כטקסט.
- `/copy [N]` — מעתיקה את התשובה האחרונה (או ה-N-ית), עם בורר לבלוקי קוד.
- `/rename [שם]` — שינוי שם הסשן.
- `/autocompact [auto|גודל]` * — קובעת באיזה גודל הקשר מתבצעת דחיסה אוטומטית, למשל `500k`. נשמרת לכל מודל.
- `/focus` * — תצוגה מצומצמת: ההנחיה האחרונה, שורת סיכום לכלים והתשובה הסופית.
- `/output-style [סגנון]` * — מציגה או מחליפה סגנון פלט.

## מודלים, עומק חשיבה וביצועים

- `/model [מודל]` — החלפת מודל ושמירתו כברירת מחדל. במקש `s` בבורר מחליפים רק לסשן הנוכחי.
- `/effort [רמה|auto|status]` — עומק החשיבה: `low`, `medium`, `high`, `xhigh`, `max` או `auto`. `max` תקף לסשן בלבד. `status` מציג את הרמה הנוכחית.
- `/effort ultracode [on|off]` * — מדליקה או מכבה את `ultracode`, שמשלב חשיבה עמוקה עם תזמור אוטומטי של תהליכי עבודה.
- `/advisor [מודל|off]` — מדליקה כלי יועץ: מודל שני שמתייעצים איתו ברגעים חשובים.
- `/fast [on|off]` — מצב מהיר.

## עבודה אוטונומית ותכנון

- `/goal [תנאי|clear]` — Claude ממשיך לעבוד עד שהתנאי מתקיים, למשל "הבדיקות עוברות". בלי ארגומנט היא מראה את המטרה הנוכחית. `clear` עוצר.
- `/loop [מרווח] [הנחיה]` — חוזרת על הנחיה כל עוד הסשן פתוח, למשל `/loop 5m check if the deploy finished`. בלי מרווח, Claude בוחר בעצמו את הקצב.
- `/workflows` * — תצוגת התקדמות של תהליכי עבודה: צפייה, השהיה, המשך ושמירה.

## סוכנים מקבילים ותזמור

- `/agents` — ניהול הגדרות של תת-סוכנים.
- `/list-agents` * — רשימת הסוכנים, חברי הצוות והסשנים שאפשר לשלוח להם הודעה, עם השם לשימוש. כינוי: `/peers`.
- `/tasks` — משימות רקע. כינוי: `/bashes`.
- `/background [הנחיה]` — מנתקת את הסשן הנוכחי כסוכן רקע. כינוי: `/bg`.
- `/batch <הוראה>` — מפרקת שינוי גדול ל-5–30 יחידות עצמאיות, ומריצה תת-סוכן בעץ עבודה נפרד לכל יחידה. מציגה תוכנית לאישור לפני כן.
- `/branch [שם]` — מסעפת את השיחה הנוכחית כדי לנסות כיוון אחר. אפשר לחזור לשיחה המקורית עם `/resume`.
- `/fork [הנחיה]` * — מעתיקה את השיחה לסשן רקע חדש, ואתה ממשיך לעבוד כאן. עם הנחיה, ההעתק מתחיל לעבוד עליה מיד.
- `/subtask <משימה>` * — תת-סוכן ברקע שיורש את כל השיחה, והתוצאה חוזרת לשיחה הנוכחית כשהוא מסיים.
- `/deep-research <שאלה>` — חיפושי רשת במקביל, בדיקה צולבת של מקורות ודוח עם ציטוטים.
- `/schedule [תיאור]` — יצירה והרצה של שגרות בענן. כינוי: `/routines`.
- `/autofix-pr [הנחיה]` — סשן ענן שעוקב אחרי ה-PR של הענף ומתקן כשלי CI והערות סקירה.

## סקירת קוד ושחרור

- `/diff` — תצוגה אינטראקטיבית של שינויים שלא נשמרו ושל שינויים לפי תור.
- `/review [PR]` — סקירת pull request מקומית.
- `/code-review [רמה] [--fix] [--comment] [--max-findings n|all|default] [יעד]` — סקירה לחיפוש באגים וניקיונות. `--fix` מחיל תיקונים, `--comment` מפרסם על ה-PR, `ultra` מריץ סקירה עמוקה בענן. הבחירה ב-`--max-findings` נשמרת עד שמחזירים ל-`default`.
- `/simplify [יעד]` — בודקת קוד שהשתנה לשימוש חוזר, פישוט ויעילות, ומחילה תיקונים. היא לא מחפשת באגים, בשביל זה יש `/code-review`.
- `/security-review` — סקירת אבטחה לקריאה בלבד של השינויים הממתינים בענף.
- `/ultrareview [PR]` — כינוי ל-`/code-review ultra`, סקירת באגים עמוקה בענן. כוללת 3 הרצות חינם בתוכניות Pro ו-Max.

## סשנים, היסטוריה ושחזור

- `/resume [סשן]` — חזרה לשיחה קודמת לפי מזהה, שם או בורר. כינוי: `/continue`.
- `/rewind` — מחזירה את הקוד ו/או השיחה לנקודת ביקורת קודמת. אפשר לשחזר גם הקשר מלפני `/clear`. כינויים: `/checkpoint`, `/undo`. בסביבות פיתוח לוחצים `Esc` פעמיים.
- `/stop` — עוצרת סשן רקע שמחוברים אליו. התמלול ועץ העבודה נשמרים.
- `/exit` — יציאה. בסשן רקע היא רק מנתקת בלי לעצור. כינוי: `/quit`.

## הגדרות, הרשאות וזיכרון

- `/config` — ממשק ההגדרות: ערכת נושא, מודל, מצב עורך (כולל Vim). כינוי: `/settings`.
- `/permissions` — כללי אפשר / שאל / אסור לכלים. כינוי: `/allowed-tools`.
- `/fewer-permission-prompts` — סורקת תמלולים ומוסיפה רשימת היתרים ל-`.claude/settings.json`.
- `/update-config [בקשה]` * — מתארים שינוי הגדרה (פקודה מותרת, משתנה סביבה, hook) ו-Claude עורך את `settings.json` המתאים.
- `/auto-mode-setup` * — מנסחת הגדרות `autoMode.environment` מתוך הפרויקט והסשנים האחרונים, ושומרת אחרי אישור.
- `/memory` — עריכת קבצי `CLAUDE.md`, הפעלת זיכרון אוטומטי וצפייה ברשומות.
- `/hooks` — הגדרות ה-hooks לפי אירוע, למשל PostToolUse בשמירת קובץ.
- `/add-dir <נתיב>` — גישה לתיקייה נוספת בלי להזיז את הסשן. שימושי ב-monorepo.
- `/cd <נתיב>` — מעבירה את הסשן לתיקיית עבודה אחרת, והשיחה נשמרת. אפשר להשלים נתיב עם `Tab`.
- `/import [codex|gemini|cursor]` * — מייבאת הגדרות מ-Codex, Gemini CLI או Cursor: קבצי הוראות, שרתי MCP, פקודות, סוכנים ו-skills. עם `--dry-run` רק מציגה מה ייובא.
- `/team-onboarding` — מדריך קליטה לצוות, מתוך היסטוריית השימוש ב-30 הימים האחרונים.
- `/theme`, `/statusline`, `/keybindings` — מראה הממשק, שורת המצב וקיצורי המקלדת.

## Skills ותוספים

- `/skills` — רשימת ה-skills. `t` ממיין לפי עלות טוקנים, ו-`Space` משנה את הנראות.
- `/skill-doctor` * — מראה מה כל skill עולה בהקשר וכמה פעמים משתמשים בו, כדי למצוא כאלה לכבות.
- `/reload-skills` — סורקת מחדש את תיקיות ה-skills בלי להפעיל מחדש.
- `/plugin [תת-פקודה]` — ניהול תוספים: `list`, `install`, `enable`, `disable` או תפריט.
- `/reload-plugins [--force]` — טוענת תוספים מחדש.
- `/run` — מפעילה את האפליקציה ומנווטת בה כדי לראות ששינוי עובד.
- `/verify` — בונה, מריצה ובודקת את התנהגות האפליקציה, לא רק את הבדיקות.
- `/run-skill-generator` — כותבת skill לפרויקט כדי ש-`/run` ו-`/verify` ידעו איך להפעיל אותו.

> פקודות מותאמות נכתבות היום כ-**skills** (`.claude/skills/`). קבצים ב-`.claude/commands/` עדיין עובדים, ואם יש skill ופקודה באותו שם, ה-skill מנצח.

## MCP, סביבות פיתוח ומעבר בין מכשירים

- `/mcp [reconnect <שרת>|enable|disable]` — ניהול חיבורי MCP ו-OAuth.
- `/mcp__<שרת>__<הנחיה>` — הנחיות דינמיות שחושף שרת MCP מחובר.
- `/ide` — ניהול שילובי IDE ומצבם.
- `/chrome` — הגדרות Claude in Chrome.
- `/teleport` — מושכת סשן מהאינטרנט לטרמינל. כינוי: `/tp`.
- `/desktop` — ממשיכה את הסשן באפליקציית שולחן העבודה. כינוי: `/app`.
- `/mobile` — קוד QR לאפליקציה בנייד. כינויים: `/ios`, `/android`.
- `/remote-control` — הופכת את הסשן לזמין מ-claude.ai. כינוי: `/rc`.
- `/terminal-setup` — מגדירה Shift+Enter וקיצורי מקשים.
- `/tui [default|fullscreen]` * — בוחרת מנוע תצוגה בטרמינל. `fullscreen` מפעיל תצוגה בלי הבהובים.

## אבחון והתקנה בענן

- `/doctor [prompt-audit [נתיב]]` — בדיקת הגדרות: מאבחנת התקנה, הגדרות, תוספים ובעיות ב-`CLAUDE.md`, ומציעה תיקונים ש-Claude מחיל אחרי אישור. `prompt-audit` בודק את ההוראות עצמן.
- `/debug [תיאור]` — מדליקה רישום דיבאג באמצע סשן.
- `/setup-bedrock`, `/setup-vertex` — אשפי הגדרה ל-Amazon Bedrock ול-Google Vertex AI.
- `/install-github-app` — מתקינה את אפליקציית GitHub של Claude למאגר, עם אפשרות להגדיר GitHub Actions.
- `/web-setup` — מחברת חשבון GitHub לסשנים בענן באמצעות פרטי ה-`gh` המקומיים.

## גילוי ותוספות

- `/insights` — דוח HTML שמנתח את דפוסי העבודה שלך ואת נקודות החיכוך.

- `/status` — לשונית סטטוס: גרסה, מודל, חשבון וקישוריות.
- `/artifacts` * — רשימת ה-artifacts שלך: מצרפים לסשן, פותחים בדפדפן או מעתיקים קישור.
- `/claude-api [migrate|upgrade|managed-agents-onboard|...]` * — חומר עזר על Claude API ו-Managed Agents לשפת הפרויקט.
- `/bug [דיווח]`, `/feedback [דיווח]` — דיווח על באג או משוב, אחרי מסך הסכמה.

## הערה על המקור

הרשימה המקורית הייתה דף ב-Notion שלא עודכן. פקודות משתנות כמעט בכל גרסה, ולכן הוספתי גם מה הוסר ומה הוחלף. כשפקודה לא עובדת, מריצים `/help` ובודקים מול [התיעוד הרשמי](https://code.claude.com/docs/en/commands).
