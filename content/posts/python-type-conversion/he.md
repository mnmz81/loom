Python כמעט לא ממיר טיפוסים בשבילכם. `"5" + 1` היא שגיאה, ולא `6`. כשצריך מספר מטקסט, או טקסט ממספר, קוראים לפונקציית המרה בעצמכם. לפונקציות יש את אותם שמות כמו הטיפוסים, כך ש-`int("5")` בונה int מהמחרוזת "5". הפוסט הזה מסביר מה כל המרה עושה, ומה משתבש כשהיא לא מצליחה.

כל דוגמה כאן הורצה עם Python 3.13. ההתנהגות נבדקה מול [התיעוד הרשמי של `int()` ופונקציות קשורות](https://docs.python.org/3/library/functions.html#int).

## מטקסט למספר

`int()` ו-`float()` קוראות מחרוזת ומחזירות מספר:

```python
print(int("42"), int("-7"), int("  8  "))
print(float("3.5"), float("1e3"))
```

```text
42 -7 8
3.5 1000.0
```

`int` מתעלמת מרווחים בשני הקצוות של הטקסט. באמצע מותרות רק ספרות (וסימן אופציונלי).

מעבירים ל-`int` ארגומנט שני כדי לקרוא בבסיס אחר. לפי התיעוד, הבסיסים המותרים הם 0 ו-2 עד 36:

```python
print(int("ff", 16), int("1010", 2))
```

```text
255 10
```

## ממספר לטקסט

`str()` הופכת כל ערך לטקסט. משתמשים בה כשרוצים לחבר טקסט ומספר עם `+`:

```python
print(str(42) + "!")
print(str(3.0), str(True))
```

```text
42!
3.0 True
```

אפשר גם לכתוב `f"{age}"`, שזה לרוב ברור יותר. הפוסט על f-strings מכסה את זה.

## מ-float ל-int: קיצוץ

`int()` על float חותך את החלק העשרוני, לכיוון האפס:

```python
print(int(3.9), int(-3.9))
```

```text
3 -3
```

זו לא עיגול. `int(3.9)` הוא 3, ולא 4. כדי לעגל משתמשים קודם ב-`round()`, ואם צריך int ממירים אחר כך. `round()` מוסברת בפוסט על פעולות מספריות.

## True ו-False כמספרים

`bool` היא תת-מחלקה של `int`, ולכן `True` נחשב 1 ו-`False` נחשב 0:

```python
print(int(True) + 1)
```

```text
2
```

## אמת ושקר: bool()

`bool()` מחזירה `True` או `False` לפי בדיקת האמת של הערך. לפי התיעוד: "אם הארגומנט שקרי או לא סופק, מוחזר False; אחרת מוחזר True". הערכים השקריים הם: `0`, `0.0`, `""`, `[]` ו-`None`. כל השאר אמת:

```python
print(bool(0), bool(""), bool([]), bool(None), bool(0.0))
print(bool("0"))
```

```text
False False False False False
True
```

`"0"` היא מחרוזת לא ריקה, ולכן היא אמת. הבדיקה עוסקת בריקנות הטקסט, ולא בערך שלו.

## בין סוגי אוספים

`list()`, `tuple()` ו-`set()` הופכות אוסף לאוסף אחר:

```python
print(list("abc"))
print(tuple([1, 2]), set([1, 1, 2]))
```

```text
['a', 'b', 'c']
(1, 2) {1, 2}
```

מחרוזת הופכת לרשימה של התווים שלה. set מוחק כפילויות, ולכן `[1, 1, 2]` הופך ל-`{1, 2}`.

## כשההמרה נכשלת

יש טקסטים שאי אפשר להפוך למספר. Python מעלה `ValueError`:

```python
int("3.5")
```

```text
ValueError: invalid literal for int() with base 10: '3.5'
```

`"3.5"` הוא מספר עשרוני, ו-`int` לא מקבל אותו. אם רוצים עשרוניים, ממירים עם `float`. מחרוזת ריקה נכשלת באותו אופן:

```python
int("")
```

```text
ValueError: invalid literal for int() with base 10: ''
```

כשהארגומנט הוא מסוג לא מתאים, מקבלים `TypeError`. למשל, `None` אינו טקסט ואינו מספר:

```python
int(None)
```

```text
TypeError: int() argument must be a string, a bytes-like object or a real number, not 'NoneType'
```

בודקים את קלט המשתמש, או תופסים את השגיאה עם `try` ו-`except`, כמו שמתואר בפוסט על input().

## טעויות נפוצות

- **ציפייה ש-`int()` יעגל.** `int(3.9)` הוא 3.
- **המרת `"3.5"` עם `int`.** משתמשים ב-`float("3.5")`.
- **הנחה ש-`"0"` שקרי.** כל מחרוזת לא ריקה היא אמת, כולל `"0"` ו-`"False"`.
- **ערבוב טקסט ומספרים עם `+`.** `"5" + 1` מעלה `TypeError`. ממירים צד אחד, למשל `int("5") + 1`.

## מה הלאה

הצעד הבא בסדרה: `input()`, שקוראת טקסט מהמשתמש, ושם המרת טיפוסים נכנסת לתמונה מיד.
