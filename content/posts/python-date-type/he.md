ל-Python אין ערך תאריך מובנה כמו `int` או `str`. תאריכים נמצאים בספרייה הסטנדרטית `datetime`, והטיפוס שבדרך כלל צריך הוא `date`. `date` מחזיק שנה, חודש ויום, ולא יותר: בלי שעה ובלי אזור זמן. לשעה משתמשים ב-`datetime`, נושא נפרד.

כל דוגמה כאן הורצה עם Python 3.13. ההתנהגות נבדקה מול [התיעוד הרשמי של אובייקטי date](https://docs.python.org/3/library/datetime.html#date-objects).

## יצירת תאריך

מייבאים את המחלקה, ומעבירים שנה, חודש ויום כמספרים שלמים:

```python
from datetime import date

d = date(2026, 10, 11)
print(d)
print(repr(d))
```

```text
2026-10-11
datetime.date(2026, 10, 11)
```

`print` מציג בפורמט ISO (`YYYY-MM-DD`). `repr` מציג איך היה נכתב האובייקט בקוד.

שלושת הארגומנטים חובה. לפי התיעוד, כל ערך חייב להיות בטווח: החודש בין 1 ל-12, והיום בין 1 למספר הימים בחודש הזה. אחרת מקבלים `ValueError`:

```python
date(2026, 2, 30)
```

```text
ValueError: day is out of range for month
```

כדי לקבל את התאריך של היום, קוראים ל-`date.today()`. הפלט שלה משתנה כל יום, ולכן הפוסט הזה לא מדפיס אותו. היא מחזירה `date`, והטיפוס שלה הוא `<class 'datetime.date'>`.

## קריאת חלקים מהתאריך

```python
print(d.year, d.month, d.day)
print(d.weekday(), d.isoweekday())
```

```text
2026 10 11
6 7
```

`weekday()` סופר מיום שני כ-0, ולכן יום ראשון הוא 6. `isoweekday()` סופר מיום שני כ-1, ולכן יום ראשון הוא 7. התיעוד משתמש בשתיהן, אז בחרו אחת והישארו איתה.

## עיצוב תאריך

`strftime` בונה טקסט מתוך מחרוזת פורמט. הקודים מתחילים ב-`%`:

```python
print(d.strftime("%d/%m/%Y"))
print(d.strftime("%A"))
print(d.isoformat())
```

```text
11/10/2026
Sunday
2026-10-11
```

`%d`, `%m` ו-`%Y` הם היום, החודש והשנה. `%A` הוא שם יום בשבוע. הרשימה המלאה של הקודים נמצאת בתיעוד של `strftime`.

כדי לקרוא תאריך מטקסט, משתמשים ב-`fromisoformat`. היא מקבלת פורמט ISO:

```python
print(date.fromisoformat("2026-01-01"))
```

```text
2026-01-01
```

לפורמטים אחרים, כמו `11/10/2026`, משתמשים ב-`datetime.strptime`. זה נושא לפוסט אחר.

## חישובים עם תאריכים

מוסיפים או מחסרים `timedelta`, שמייצג משך זמן:

```python
from datetime import timedelta

print(d + timedelta(days=30))
```

```text
2026-11-10
```

חיסור של שני תאריכים נותן `timedelta`:

```python
print(d - date(2026, 1, 1))
print((d - date(2026, 1, 1)).days)
```

```text
283 days, 0:00:00
283
```

`.days` מחזירה את מספר הימים כמספר שלם, וזה בדרך כלל מה שצריך לחישוב.

אפשר להשוות תאריכים עם `<`, `>` ו-`==`:

```python
print(d > date(2026, 1, 1))
```

```text
True
```

## טעויות נפוצות

- **שימוש במחרוזת במקום תאריך.** `"2026-10-11" > "2026-01-01"` משווה טקסט. זה עובד במקרה רק בפורמט ISO. ממירים קודם עם `fromisoformat`.
- **ציפייה לשעה בתוך `date`.** ל-`date` אין שעות, דקות או אזור זמן. אם צריך אותם, משתמשים ב-`datetime`.
- **בלבול בין שתי שיטות `weekday`.** `weekday()` מתחיל מ-0 ביום שני. `isoweekday()` מתחיל מ-1.

## מה הלאה

הצעד הבא בסדרה: פעולות על מספרים, כולל `/`, `//`, `%` ו-`**`.
