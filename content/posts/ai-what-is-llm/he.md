LLM (מודל שפה גדול) היא תוכנה שמקבלת טקסט ומחזירה טקסט. ChatGPT, Claude ו-Gemini הם מוצרים שנבנו על גבי LLM. הפוסט הזה מסביר מה קורה בלולאה בפנים ברמה הפשוטה ביותר, ואז מבצע קריאה ראשונה מ-Python.

הקוד מבוסס על [ה-quickstart הרשמי של Anthropic](https://platform.claude.com/docs/en/get-started). הוא לא הורץ בשביל הפוסט, ולכן כל בלוק פלט כאן הוא **פלט לדוגמה**: המבנה תואם לתיעוד, אבל הטקסט של תשובה אמיתית יהיה שונה בכל הרצה.

## מה זה LLM

LLM היא פונקציה גדולה מאוד. היא אומנה על כמות עצומה של טקסט, ולמדה משימה אחת: בהינתן הטקסט עד עכשיו, להעריך איזה קטע טקסט צפוי להופיע אחריו.

הקטעים האלה נקראים טוקנים (tokens). טוקן הוא בדרך כלל מילה או חלק ממילה. הפוסט על [טוקנים וחלון ההקשר](he/posts/ai-tokens-context-window/) מסביר אותם לעומק. בינתיים, תחשבו על טוקן כעל פיסת טקסט קטנה.

כל השאר, כמו מענה לשאלות, תרגום, סיכום או כתיבת קוד, נובע מהיכולת האחת הזו. אף אחד לא כתב כלל לתרגום. המודל למד אותו כי טקסט מתורגם היה חלק ממה שהוא למד ממנו.

## איך נוצר הטקסט

המודל לא כותב תשובה שלמה בבת אחת. הוא מריץ לולאה:

1. הוא קורא את כל הטקסט עד עכשיו.
2. הוא מחשב הסתברות לכל טוקן אפשרי הבא.
3. נבחר טוקן אחד, בדרך כלל אחד סביר.
4. הטוקן מתווסף לטקסט, והלולאה מתחילה מחדש.

![המודל קורא את הטקסט עד עכשיו, מחשב הסתברויות לטוקן הבא, נבחר טוקן אחד שמתווסף לטקסט, והלולאה חוזרת](/images/ai-what-is-llm/next-token-loop.svg)

הלולאה נעצרת כשהמודל מוציא טוקן עצירה מיוחד, או כשהוא מגיע למגבלת הטוקנים שהגדרתם. מכיוון שהטוקן נבחר מתוך התפלגות הסתברויות, אותה שאלה יכולה להניב תשובות שונות. זה גם שורש ההזיות: המודל מייצר טקסט שסביר, לא טקסט שנבדק. שני הנושאים האלה מוסברים בפוסט מאוחר יותר.

## הקריאה הראשונה

כדי לקרוא למודל צריך מפתח API במשתנה הסביבה `ANTHROPIC_API_KEY` ואת החבילה `anthropic` (`pip install anthropic`). ה-SDK קורא את המפתח מהסביבה בעצמו.

```python
import anthropic

client = anthropic.Anthropic()

message = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1000,
    messages=[{"role": "user", "content": "In one sentence, what is an LLM?"}],
)

for block in message.content:
    if block.type == "text":
        print(block.text)
```

שלושת הפרמטרים `model`, `max_tokens` ו-`messages` הם חובה, לפי [התיעוד של ה-Messages API](https://platform.claude.com/docs/en/api/messages). `max_tokens` הוא תקרה לאורך התשובה, לא יעד. תוכן התשובה הוא רשימה של בלוקים, ולכן הקוד עובר עליהם ומדפיס את אלה מסוג טקסט.

```text
An LLM is a neural network trained on large amounts of text to predict the next
token, which lets it generate, summarize and translate language.
```

זה פלט לדוגמה. שמות מודלים משתנים עם הזמן, ולכן בדקו ב-[סקירת המודלים](https://platform.claude.com/docs/en/models/overview) מהי הרשימה העדכנית לפני שאתם מעתיקים את השם שלמעלה.

## מה חוזר בתשובה

התשובה היא יותר מטקסט. היא גם אומרת למה המודל עצר וכמה טוקנים הקריאה השתמשה:

```python
print(message.stop_reason)
print(message.usage.input_tokens, message.usage.output_tokens)
```

```text
end_turn
17 31
```

הערך `end_turn` ב-`stop_reason` אומר שהמודל סיים בעצמו. הערך `max_tokens` אומר שהתשובה נקטעה במגבלה שלכם. `usage` סופר טוקנים נכנסים ויוצאים, ועל זה משלמים. המספרים למעלה הם פלט לדוגמה.

## לאן הסדרה ממשיכה

הבנת הלולאה מסבירה את רוב מה שיבוא אחר כך: למה לחלון ההקשר יש גבול, למה ה-prompt חשוב, למה מודל יכול להישמע בטוח ולטעות, ולמה מתן כלים או מסמכים משנה מה הוא יכול לעשות.

הפוסטים הבאים בסדרה עוסקים באיך מודלים נבנים, בטוקנים ובחלון ההקשר, ב-prompting, בפלט מובנה, במודלי חשיבה ובקלט מולטימודלי. אחריהם יבואו RAG, כלים וסוכנים, fine-tuning, ומה נדרש כדי להריץ את כל זה בייצור.
