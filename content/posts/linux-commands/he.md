הפקודות שאני שולף על שרת Linux, בתוך container או במשימת CI. הדוגמאות מניחות **GNU/Linux** עם shell בסגנון Bash; ב-Mac הגרסאות של BSD שונות בפרטים, ואיפה שזה משנה אני מציין את זה. Linux רגישה לאותיות גדולות וקטנות: `File.txt` ו-`file.txt` הם שני קבצים שונים. סימן ⚠️ אומר שהפקודה יכולה להרוס נתונים: מריצים קודם את הגרסה הלא מזיקה (`ls` לפני `rm`, ‏`find` בלי `-delete`) ומסתכלים. Linux חד-פעמי לתרגול נמצא במרחק פקודה אחת: `docker run --rm -it ubuntu bash` (ראו [Docker מאפס לגיבור](he/posts/docker-zero-to-hero/)).

## לקבל עזרה

- `man <פקודה>` פותחת את דף המדריך. `/מילה` מחפשת בתוכו, `n` מעבירה להתאמה הבאה, ו-`q` יוצאת.
- `<פקודה> --help` מדפיסה סיכום שימוש קצר.
- `man -k <מילה>` (או `apropos <מילה>`) מחפשת בדפי המדריך לפי מילת מפתח כשלא יודעים את שם הפקודה.
- `type <פקודה>` מראה אם משהו הוא תוכנה, פקודה מובנית ב-shell או alias, ו-`which <פקודה>` מראה את הנתיב של התוכנה שתרוץ.
- ה-[GNU Coreutils manual](https://www.gnu.org/software/coreutils/manual/) מפרט לעומק את כלי הקבצים והטקסט הבסיסיים.

## איפה אני, ואיך זזים

- `pwd` מדפיסה את התיקייה הנוכחית, ו-`cd <תיקייה>` משנה אותה. `cd` לבדה חוזרת הביתה, `cd -` קופצת לתיקייה הקודמת, ו-`cd ..` עולה רמה אחת.
- `ls` מציגה קבצים. `ls -l` היא התצוגה הארוכה, `ls -a` כוללת קבצים מוסתרים (שמות שמתחילים בנקודה), `ls -h` מציגה גדלים קריאים, והם משתלבים: `ls -lah`. מוסיפים `-t` למיון לפי זמן שינוי ו-`-S` לפי גודל.
- `~` היא תיקיית הבית שלנו, `.` היא התיקייה הנוכחית ו-`..` היא תיקיית האב שלה.
- לוחצים **Tab** להשלמת שמות ו-**Tab Tab** להצגת האפשרויות.

## עבודה עם קבצים ותיקיות

- `touch <קובץ>` יוצרת קובץ ריק, או מעדכנת את זמן השינוי של קובץ קיים.
- `mkdir <תיקייה>` יוצרת תיקייה, ו-`mkdir -p a/b/c` יוצרת את כל הנתיב (בלי שגיאה אם הוא כבר קיים).
- `cp <מקור> <יעד>` מעתיקה קובץ, `cp -r <תיקייה> <יעד>` מעתיקה תיקייה, ו-`cp -a` מעתיקה ושומרת הרשאות וזמנים.
- `mv <מקור> <יעד>` מעבירה או משנה שם. כמו `cp`, היא דורסת יעד קיים בשקט: מוסיפים `-i` כדי שישאלו קודם, או `-n` כדי שלא תדרוס לעולם.
- `rm <קובץ>` מוחקת קובץ. `rm -r <תיקייה>` מוחקת תיקייה ואת כל מה שבתוכה, ו-`rm -rf <תיקייה>` עושה זאת בלי לשאול ⚠️. אין סל מחזור. קוראים את הנתיב פעמיים ונזהרים ממשתנים (`rm -rf "$DIR/"` כש-`$DIR` ריק הוא האסון הקלאסי).
- `ln -s <יעד> <קישור>` יוצרת קישור סימבולי (מצביע לנתיב). בלי `-s` היא יוצרת קישור קשיח.
- `file <שם>` אומרת איזה סוג קובץ זה, ו-`stat <קובץ>` מציגה גודל, הרשאות, בעלים וחותמות זמן.
- שמות עם רווחים עוטפים במירכאות: `cp "My File.txt" backup/`.

## מסתכלים בקבצים

- `cat <קובץ>` מדפיסה קובץ, ו-`cat a b > c` מחברת קבצים.
- `less <קובץ>` היא הצופה לקבצים ארוכים: חצים או `Space` לגלילה, `/מילה` לחיפוש, `q` ליציאה. `less +F <קובץ>` עוקבת אחרי קובץ כמו `tail -f` (‏`Ctrl-C` מפסיק לעקוב).
- `head <קובץ>` מציגה את 10 השורות הראשונות ו-`tail <קובץ>` את 10 האחרונות. `-n 50` משנה את המספר.
- `tail -f <קובץ>` משאירה את הקובץ פתוח ומדפיסה שורות חדשות כשהן מגיעות, וככה צופים בלוג. `tail -F` שורדת גם סיבוב לוגים (log rotation).
- `wc -l <קובץ>` סופרת שורות (`-w` מילים, `-c` בתים).
- `diff a b` מראה את ההבדלים בין שני קבצים, ו-`diff -u a b` מדפיסה אותם בפורמט ה-unified המוכר.

## חיפוש

- `grep "טקסט" <קובץ>` מדפיסה את השורות שמתאימות. הדגלים שישמשו אתכם: `-i` מתעלם מאותיות גדולות וקטנות, `-n` מציג מספרי שורות, `-v` הופך (שורות שלא מתאימות), `-c` סופר התאמות, `-w` מילים שלמות, `-E` ביטויים רגולריים מורחבים, ו-`-A 2` / `-B 2` / `-C 2` לשורות אחרי, לפני וסביב כל התאמה.
- `grep -rn "טקסט" .` מחפשת בכל קובץ מתחת לתיקייה הנוכחית. מוסיפים `--include='*.py'` כדי להגביל לפי שם, ו-`-l` כדי לרשום רק את הקבצים שמתאימים.
- `find <איפה> <תנאים>` מוצאת קבצים לפי התכונות שלהם:

```bash
find . -name "*.log"                  # by name (quote the pattern, or the shell expands it)
find . -iname "readme*"               # same, ignoring case
find . -type d -name node_modules     # only directories (f = files)
find . -type f -size +100M            # bigger than 100 MiB
find . -mtime -1                      # modified in the last 24 hours
find . -mtime +30                     # modified more than 30 days ago
find . -mmin -10                      # modified in the last 10 minutes
find . -name "*.tmp" -delete          # delete matches ⚠️ (put -delete last, and run without it first)
find . -name "*.sh" -exec chmod +x {} +   # run a command on the matches
find / -name "nginx.conf" 2>/dev/null     # search everywhere, hide "permission denied" noise
```

- `find ... -print0 | xargs -0 <פקודה>` היא הדרך הבטוחה להעביר שמות קבצים לפקודה אחרת, כי היא מתמודדת עם רווחים ושורות חדשות בשמות.
- `locate <שם>` מחפשת באינדקס מוכן והיא הרבה יותר מהירה מ-`find`, אבל דורשת `plocate` או `mlocate` ואינדקס מעודכן (`sudo updatedb`).

## ארכיונים ודחיסה

- `tar czf backup.tar.gz <תיקייה>` יוצרת ארכיון דחוס ב-gzip: `c` יצירה, `z` gzip, `f` שם הקובץ שבא אחריו. משתמשים ב-`J` במקום `z` ל-xz, וב-`j` ל-bzip2.
- `tar xzf backup.tar.gz` מחלצת אותו, `tar tzf backup.tar.gz` רושמת את התוכן, ו-`-C <תיקייה>` מחלצת למקום אחר: `tar xzf backup.tar.gz -C /tmp/restore`. מוסיפים `-v` כדי לראות כל קובץ. ‏`tar xf` מודרנית בדרך כלל מזהה את הדחיסה בעצמה.
- `tar czf backup.tar.gz --exclude=node_modules <תיקייה>` משאירה דברים בחוץ.
- `gzip <קובץ>` דוחסת קובץ בודד (ומחליפה אותו ב-`<קובץ>.gz`), ו-`gunzip <קובץ>.gz` הופכת זאת.
- `zip -r archive.zip <תיקייה>` ו-`unzip archive.zip` מטפלות בפורמט הידידותי ל-Windows, וייתכן שצריך להתקין אותן.
