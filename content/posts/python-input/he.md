`print()` כותבת למסך. `input()` עושה את ההפך: מציגה הנחיה אופציונלית, מחכה שהמשתמש יקליד שורה וילחץ Enter, ומחזירה את מה שהוקלד. זו הדרך הפשוטה ביותר לגרום לסקריפט להיות אינטראקטיבי.

כל דוגמה כאן הורצה עם Python 3.13. ההתנהגות נבדקה מול [התיעוד הרשמי של `input()`](https://docs.python.org/3/library/functions.html#input).

## הקריאה הבסיסית

```python
name = input("What is your name? ")
print(f"Hello, {name}!")
```

הטקסט בסוגריים הוא ההנחיה. היא נכתבת למסך בלי ירידת שורה, כך שהסמן מחכה מיד אחריה. לפי התיעוד, השורה נקראת, "מומרת למחרוזת (תוך הסרת ירידת השורה בסוף)", ומוחזרת.

אם מקלידים `Ada`, המסך מציג:

```text
What is your name? Ada
Hello, Ada!
```

ה-`Ada` אחרי ההנחיה הוא מה שהקלדתם. התוכנית לא מדפיסה אותו.

## התוצאה תמיד str

גם כשהמשתמש מקליד ספרות, `input()` מחזירה טקסט:

```python
age = input("How old are you? ")
print(type(age))
```

אם מקלידים `36`, זה מדפיס:

```text
<class 'str'>
```

לכן `age + 1` זורק `TypeError`. צריך להמיר את הטקסט קודם:

```python
age = input("How old are you? ")
years = int(age) + 1
print(f"Next year: {years}")
```

למספרים עם נקודה עשרונית משתמשים ב-`float()`. פונקציות ההמרה מוסברות בפוסט על המרת טיפוסים.

## הרווחים נשמרים

`input()` מסירה רק את ירידת השורה בסוף. הרווחים נשארים:

```python
print(repr(input("Anything: ")))
```

אם מקלידים `  spaced  ` ולוחצים Enter, הפלט הוא:

```text
'  spaced  '
```

`repr()` מציגה את הגרשיים, כך שרואים את הרווחים. כדי להסיר רווחים משני הקצוות, משתמשים ב-`strip()`, מתודת המחרוזות מהפוסט על מחרוזות.

## טעות נפוצה: קלט לא תקין

המשתמש יכול להקליד כל דבר, ולכן המרה עלולה להיכשל:

```python
age = input("How old are you? ")
print(int(age))
```

אם המשתמש מקליד `thirty`, התוכנית עוצרת:

```text
ValueError: invalid literal for int() with base 10: 'thirty'
```

בתוכנית אמיתית בודקים את הקלט לפני ההמרה, או תופסים את השגיאה עם `try` ו-`except`. לעיתים בדיקה מהירה עם מתודת מחרוזת מספיקה:

```python
text = input("How old? ")
print(text.isdigit())
```

אם מקלידים `36`, זה מדפיס `True`. `isdigit()` מקבלת רק ספרות, ולכן `-5` ו-`3.5` מחזירים `False`.

## כשאין קלט

כשזרם הקלט נגמר, `input()` זורקת שגיאה במקום להחזיר מחרוזת ריקה. זה קורה כשסקריפט רץ בלי טרמינל מחובר, למשל בתוך pipeline או מקובץ:

```python
name = input("What is your name? ")
```

```text
EOFError: EOF when reading a line
```

לפי התיעוד: "כשמגיעים ל-EOF, מועלה EOFError". שורה ריקה (לחיצה על Enter בלי להקליד) שונה: היא מחזירה `""`, והתוכנית ממשיכה לרוץ.

## טעויות נפוצות

- **שכחה של רווח בסוף ההנחיה.** `input("Name?")` מציב את הסמן מיד אחרי סימן השאלה. מוסיפים רווח בסוף ההנחיה אם רוצים מרווח.
