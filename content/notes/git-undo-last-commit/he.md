ביטול הקומיט האחרון כשהוא **עוד לא נדחף** (push). ההבדל בין האפשרויות הוא מה קורה לשינויים:

```bash
git reset --soft HEAD~1   # מבטל את הקומיט, השינויים נשארים ב-staging
git reset HEAD~1          # (--mixed, ברירת המחדל) השינויים נשארים בקבצים, לא ב-staging
git reset --hard HEAD~1   # מוחק את הקומיט ואת השינויים — זהירות!
git revert HEAD           # הקומיט כבר נדחף? יוצר קומיט הפוך במקום לשכתב היסטוריה
```

רק רציתם לתקן את ההודעה או להוסיף קובץ ששכחתם? `git commit --amend`.

נמחק משהו בטעות עם `--hard`? `git reflog` מראה את ה-hash הקודם, ו-`git reset --hard <hash>` מחזיר אותו.
